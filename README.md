# Introdução ao Python 3 e ao framework Flask

Este repositório contém o site em HTML do curso «Introdução ao Python 3 e ao framework Flask através de exemplos».

🔗 **Ver a documentação online:** [https://stahe.github.io/pt-python-flask-sept-2020/](https://stahe.github.io/pt-python-flask-sept-2020/)

---

## 📝 Conteúdo

Este projeto oferece uma lista de scripts em Python que abrangem diversos temas:
* Os fundamentos da linguagem.
* Gestão de bases de dados MySQL e PostgreSQL.
* Programação de redes TCP/IP (protocolos HTTP, POP3, IMAP, SMTP).
* Programação web MVC com o framework Flask.
* Arquiteturas de três camadas e programação baseada em interfaces.

## 🎯 Público-alvo

Esta compilação de exemplos destina-se a:
* Desenvolvedores que já tenham utilizado uma linguagem de script (Perl, PHP, VBScript).
* Desenvolvedores familiarizados com linguagens tipadas (Java, C#) que desejem explorar uma linguagem de script orientada a objetos.

> ⚠️ **Nota:** Este documento não é adequado para leitores com pouca ou nenhuma experiência em programação.

## 💡 Filosofia

Este projeto não é nem um curso exaustivo nem uma compilação de «boas práticas». O seu objetivo é fornecer exemplos concretos que o ajudem a dar os primeiros passos com Python 3 e Flask. O código é fornecido tal como está, e alguns scripts podem ser otimizados.

Para tirar o máximo partido deste conteúdo, é necessária uma **leitura ativa**: deve analisar o código, ler os comentários associados e observar os resultados da execução.
